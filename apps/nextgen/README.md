# NextGen - Innovation Platform

Next Generation Solutions Platform (nextgen.artemis.com)

## Quick Start

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

## Structure

Same as `apps/consultancy/`:
- `src/pages/` - Route components
- `src/components/` - Reusable UI components
- `src/layouts/` - Layout wrappers
- `src/routes/` - Route configuration
- `src/assets/` - Images and global styles
- `src/hooks/` - Custom React hooks
- `src/utils/` - Utilities

## Build

```bash
npm run build
```

Builds to `build/` folder for deployment to nextgen.artemis.com

## Content Ideas

- AI/ML product showcase
- Innovation lab and research
- Technology partnerships
- Product documentation
- API reference and developer tools
- Thought leadership and technical articles

## Customization

1. Add new pages to `src/pages/`
2. Update `src/routes/index.js` with new routes
3. Create components as needed in `src/components/`
4. Customize styles in `src/assets/styles/`

This app uses the same architecture as the consultancy app - fully independent with no cross-app dependencies.
